О HTML

HTML (язык гипертекстовой разметки) — это стандартный язык для создания веб-страниц. Он задаёт структуру контента и работает вместе с CSS для оформления.

  • Элементы задаются с помощью тегов.
  • HTML легко изучить и широко использовать.
  • Основные теги: <div>, <header>, <footer>, <main>.

О CSS

CSS (каскадные таблицы стилей) используется для оформления структуры, заданной HTML. С помощью CSS можно управлять макетом, цветами, шрифтами и адаптивностью сайта.

  • CSS делает сайты визуально привлекательными.
  • Основные функции: селекторы, свойства и медиазапросы.
  • Flexbox и Grid упрощают создание макетов.
